# 静态素材生成(asset-gen)

三步:**生图(纯色底)→ 抠透明+裁剪 → 验收入库**。

## 1. 生图(tuzi-image 技能)

**背景色和素材主色对比选**(决定抠图质量的关键):

| 素材主色 | 背景色 |
|----------|--------|
| 暖色(红/橙/金,角色立绘常见) | 绿幕 `#00FF00` |
| 绿色系(草药/自然/毒) | 品红 `#FF00FF` |
| 蓝紫冷色 | 绿 `#00FF00` 或黄 |
| 发光体(火焰/光效) | 纯黑 → **走 vfx-pipeline,不归这里** |

prompt 骨架:`<素材描述>,游戏图标/素材,solid flat chroma key background, #00FF00 green, no checkerboard, no gradient, no texture,居中,无文字无水印`。gpt-image-2 不支持 transparent,一律 `--background opaque` + 纯色 prompt。

## 2. 抠透明 + 裁剪

```bash
python scripts/chroma_key.py 生成图.png --out 素材.png --color auto --pad 12 [--max-size 512]
```

自动检测背景色、色距抠图、去彩边、bbox 裁剪、可选缩放,并输出**质量判定**。

## 3. 铁律:不好抠就重新生成,禁止本地硬修

脚本输出 `VERDICT: REGENERATE`(前景撞背景色 / 彩边残留超标),或肉眼看到绿边/品红边/图案破损时:**换个背景色改 prompt 重新生成一张**(约 1 分钟),不要叠加二次三次清边补救 —— 硬修出来的素材边缘永远脏,重生成永远更快更干净。这是本流水线的第一原则。

## 4. 验收 + 入库

- 每张产出用 Read 看一遍:边缘干净、无背景残留、内容完整
- 入库项目 `design/` 对应目录(icons/、items/、characters/、ui/…),命名用语义 slug(如 `icon-gold.png`、`h01-zhuyan-full.png`)
- 同类素材保持同一 prompt 骨架只换主体描述,风格才统一;批量时并行生成、逐张验收

## 常见素材的参数建议

| 类型 | 生图尺寸 | --max-size | 说明 |
|------|---------|-----------|------|
| 物品/货币/技能图标 | 1024x1024 | 256 | 方形构图 |
| 角色立绘整图(开发期占位,后期再拆骨骼) | 1024x1536 | 0(保留原尺寸) | 全身居中站姿;后续 portrait-to-animation 拆分复用同一张 |
| 按钮/UI 装饰件 | 1024x1024 | 512 | — |
| 场景背景 | 1536x1024 | 0 | 不抠图,直接用 |
