# Assets

Use semantic and versioned filenames.

Recommended pattern:

```text
common/icon-heart-v1.png
common/bottom-nav-home-v1.png
pages/home/main-banner-v1.png
pages/shop/shop-cover-ginza-v1.png
```

If Pencil still shows an old image after replacement, create a new `-v2` file and update the image fill URL.
